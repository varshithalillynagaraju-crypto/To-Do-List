# To-Do-List
This project is a basic task management application developed with Java Swing. Users can add tasks to a list, view all pending tasks, and remove selected tasks. The application provides a clean and simple interface for managing daily activities while showcasing core Java GUI programming concepts.

Key Features

Add new tasks

View tasks in a list

Remove completed tasks

Simple and intuitive GUI

Built entirely with Java Swing


Technologies Used

Java

Java Swing

Event Handling

Collections (DefaultListModel)
